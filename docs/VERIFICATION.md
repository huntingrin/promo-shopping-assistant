# v0.1.0 验证记录

日期：2026-10-20。运行环境的精确版本与自动化测试结果见 [test-run.txt](test-run.txt)。

## 已验证

- `python3 -m unittest discover -s tests -v`：53项测试通过。其中沿用上游22项内核测试，包含50组带固定随机种子的购物车与独立穷举算法交叉核对。
- Skill 创建工具的 `quick_validate.py`：入口元数据、名称及脚手架检查通过。
- 原清单、明确批准清洁布后的最低支出和最少操作方案分别为390元/1次、345元/2次、375元/1次。
- 预售案例：完整支出720元、已付100元、本次应付620元。
- 从任意工作目录运行CLI，整体复制脚本和案例后可以独立运行，不依赖相邻研究目录。
- 任务流程：创建、读取、批准具体候选、求解、记录已购、扣减数量及账户券次数、再次求解剩余商品。
- 第一单200元记账后，剩余最省方案145元；结果同时显示已购200元、剩余145元及整次预计345元。
- 已消耗优惠的余额在商品/规则清理后保留；重新添加同ID优惠且未重新指定余额时，不恢复已用掉的券。
- 修改价格、数量、商品选择、偏好和券次数后重新计算；更新清空当前结果，历史仍保留。
- 资料版本冲突拒绝写入；直接修改输入后指纹失配，隐藏旧结果。
- 缺价格、运费、优惠条件或存在未解决关键问题时不返回金额方案；超规模清单保留全部资料。
- 无效输入和超时返回明确状态；比较失败替换旧结果，不返回部分方案冒充完整结果。
- 跨平台最少次数约束、同基准净节省、负数节省到分、来源缺失提示、实际结算差异补问。
- 原子写文件、同任务并发锁、凭据ID去重和实际用券校验。
- `build_release.py` 生成可整体迁移的zip及SHA-256；解压包独立运行演示和测试，分发内容不含任务、Git目录或缓存。

## 尚未验证/尚未实现

- 尚未使用真实购物车和平台结算预览验价，也未进行目标用户试用。
- 尚未在多种品牌 Agent 中分别验证自动发现、视觉提取、截图去重及跨对话恢复；这些能力依赖宿主与具体工具。
- CLI已在当前macOS/Python环境测试；代码以Python 3.10+标准库编写，尚未逐一实测其他Python版本、Windows和Linux。
- 没有自带OCR或自然语言模型；宿主Agent按Skill整理输入，确定性计算与状态管理由程序实现。
- 百分比/件数折扣、支付权益、返现/赠券循环、退货凑单及加购预算约束没有建模。

金额示例都是假设情景，不是任何平台当前报价。自动化通过证明本次覆盖范围内的程序行为，不代表真实平台完整规则或各宿主体验已验证。
